# 📺 StreamZX - Live TV & Streaming WebApp

**StreamZX** হলো একটি আধুনিক, দ্রুত এবং রেসপন্সিভ লাইভ টিভি ও স্ট্রিমিং ওয়েব অ্যাপ্লিকেশন। এটি HTML, CSS এবং Pure JavaScript দিয়ে তৈরি এবং **Telegram WebApp** হিসেবেও ব্যবহারের জন্য উপযোগী।

---

## ✨ বৈশিষ্ট্যসমূহ (Features)

- 🔴 **Live Events:** লাইভ স্পোর্টস ও স্পেশাল ইভেন্টের জন্য আলাদা সেকশন।
- ⚽ **বিভাগ অনুযায়ী চ্যানেল (Categories):** Sports, Entertainment, News, Movies, Islamic, Kids, Music ইত্যাদি ক্যাটাগরি।
- ⭐ **প্রিয় চ্যানেল (Favorites):** পছন্দের চ্যানেলগুলো স্টার আইকনে ক্লিক করে সেভ করে রাখার সুবিধা (LocalStorage এ সংরক্ষিত থাকে)।
- 🔍 **রিয়েল-টাইম সার্চ (Instant Search):** ঝটপট চ্যানেল খুঁজে বের করার জন্য লাইভ সার্চ বার।
- 🎬 **HLS Player সাপোর্ট:** `.m3u8` ও সাধারণ ভিডিও স্ট্রিমিং সাপোর্ট করার জন্য HLS.js ইন্টিগ্রেশন।
- ⚙️ **Custom Network Stream:** সেটিংস থেকে যেকোনো কাস্টম M3U8/Video URL পেস্ট করে সরাসরি প্লে করার সুবিধা।
- 📢 **Monetag Ads Integration:** চ্যানেল প্লে করার সময় Monetag Pop/Interstitial এড সাপোর্ট।
- 📱 **Mobile-First UX:** স্মুথ বটম নেভিগেশন বার, স্টাইলিশ ড্রয়ার সাইডবার এবং ডার্ক থিম UI।
